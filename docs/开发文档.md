# ClipLink 开发文档

> 版本：1.0  
> 日期：2026-09-16  
> 定位：通过 ZeroTier，在两台 Windows 电脑之间双向同步纯文字剪贴板。

## 1. 产品目标

ClipLink 是一个简洁、轻量的 Windows 托盘工具。两台电脑加入同一个 ZeroTier 网络并运行 ClipLink 后，输入对方的 ZeroTier IPv4 地址，完成一次配对，即可自动双向同步剪贴板文字。

### 核心原则

- 简单：无账号、无云服务器、无复杂网络设置。
- 实用：只解决两台电脑之间的文字剪贴板同步。
- 安全：未经确认的设备不能收发内容。
- 轻量：关闭窗口后常驻托盘。
- 稳定：自动重连、消息去重、不形成回传循环。

### 第一版包含

1. 自动识别并显示本机 ZeroTier IPv4。
2. 输入对方 IP 并连接。
3. 首次配对确认。
4. 双向同步纯文字。
5. 防止内容重复回传。
6. 断线自动重连。
7. 暂停和恢复同步。
8. 清晰的连接、同步和错误提示。
9. 系统托盘。
10. 可选开机启动。
11. 保存配对设备和设置。
12. Windows 安装包。

### 第一版不包含

- 图片、文件或富文本格式同步。
- 剪贴板历史正文。
- 多设备同步。
- 手机端、云账号或公网中继。

## 2. 用户流程

### 首次使用

1. 两台电脑加入同一个 ZeroTier 网络。
2. 分别安装并启动 ClipLink。
3. 两边自动显示自己的 ZeroTier IP。
4. 在电脑 A 输入电脑 B 的 IP，点击“连接”。
5. 电脑 B 显示电脑 A 的设备名、IP 和六位确认码。
6. 两边确认码一致后，电脑 B 点击“允许并记住”。
7. 双方显示绿色“已连接”。
8. 任意一边复制文字，另一边剪贴板自动更新。

### 后续启动

1. 读取已保存的配对信息。
2. 自动尝试连接上次设备。
3. 对方未启动时进入自动重连。
4. 连接恢复后只同步新内容，不补发断线期间的旧内容。

### 暂停同步

暂停后保持连接，但停止读取、发送和写入剪贴板。恢复后只处理新复制的内容，暂停期间的内容不补发。

## 4. 技术方案

### 技术栈

- 桌面框架：Tauri 2。
- 前端：Vue 3、TypeScript、Vite。
- 核心：Rust。
- 异步运行时：Tokio。
- 网络：TCP 长连接。
- 消息：4 字节长度前缀加 JSON。
- 剪贴板：`arboard`，仅使用文字接口。
- 序列化：`serde`、`serde_json`。
- 摘要：SHA-256。
- 消息认证：HMAC-SHA256。
- 配置：应用数据目录中的 JSON。
- 日志：`tracing`，禁止记录剪贴板正文。

### 网络参数

- 默认端口：`45888/TCP`。
- 连接目标：`对方 ZeroTier IP:45888`。
- 监听地址：优先绑定本机 ZeroTier IP，不监听全部网卡。
- 单条消息上限：1 MiB。
- 连接超时：5 秒。

### 后台任务

1. `network_listener`：监听对方连接。
2. `connection_manager`：主动连接、状态和重连。
3. `clipboard_worker`：单线程访问 Windows 剪贴板。
4. `heartbeat_worker`：发送心跳、判断失联。
5. `config_worker`：保存配置和配对信息。

剪贴板访问集中到一个工作线程，避免并发访问 Windows 剪贴板。

## 7. ZeroTier IP 检测

1. 枚举 Windows 网络适配器。
2. 查找名称或描述包含 `ZeroTier` 的网卡。
3. 读取该网卡的 IPv4 地址。
4. 排除回环地址、链路本地地址和 `0.0.0.0`。
5. 找到有效地址后更新状态并通知界面。
6. 每 10 秒复查；连接失败或网卡变化时立即复查。

不能只根据 `10.x.x.x` 等网段判断，因为普通局域网也可能使用私有地址。必须结合网卡名称或描述。

未检测到时显示：“未发现 ZeroTier IP，请确认 ZeroTier 已启动，并且本机已经加入并获准访问网络。”

## 8. 通信协议

### 消息边界

```text
4 字节无符号大端整数：JSON 字节长度
N 字节：UTF-8 JSON
```

接收端先检查长度，再分配缓冲区和解析 JSON。

### 公共结构

```json
{
  "version": 1,
  "type": "clipboard_update",
  "message_id": "UUID",
  "timestamp": 1789550000000,
  "device_id": "发送方设备 ID",
  "payload": {},
  "auth": "HMAC-SHA256"
}
```

### 消息类型

- `hello`：交换版本和设备信息。
- `pair_request`：首次配对请求。
- `pair_response`：允许或拒绝。
- `auth_challenge`：随机认证挑战。
- `auth_response`：挑战响应。
- `clipboard_update`：纯文字更新。
- `pause_state`：暂停状态。
- `ping` / `pong`：心跳。
- `disconnect`：正常断开。
- `error`：协议错误。

协议版本固定为 `1`。版本不兼容时停止同步并提示更新。

## 9. 配对与认证

### 首次配对

1. A 连接 B。
2. 双方交换设备 ID、设备名和随机数。
3. 根据本次握手内容计算相同的六位确认码。
4. 两边显示确认码。
5. B 点击“允许并记住”或“拒绝”。
6. 允许后双方生成并保存共享密钥。
7. 配对完成后进入已连接状态。

### 后续认证

1. 接收方生成一次性随机挑战。
2. 发起方用共享密钥计算 HMAC。
3. 接收方验证结果。
4. 成功后允许同步；失败则断开并要求重新配对。

配对后的业务消息都必须携带 HMAC。认证内容包括版本、类型、消息 ID、时间戳、设备 ID 和完整 payload。收到消息后先认证，再处理正文。

### 解除配对

断开连接，删除共享密钥、对方信息和自动重连目标。下次连接必须重新确认。

## 10. 剪贴板同步逻辑

### 本地监听

1. 每 300 毫秒读取一次纯文字。
2. 读取失败时跳过本轮并稍后重试。
3. 对文字计算 SHA-256。
4. 与上次观察到的哈希比较。
5. 未变化则不处理。
6. 如果是刚写入的远程内容，则不发送。
7. 否则发送 `clipboard_update`。

### 收到远程文字

1. 验证消息大小、结构、身份和 HMAC。
2. 检查消息 ID 是否已经处理。
3. 验证正文哈希。
4. 记录远程写入哈希。
5. 将纯文字写入剪贴板。
6. 更新本地观察哈希。
7. 通知界面更新“最近同步”。

### 防循环

同时使用三层保护：消息 ID 去重、短时间内容哈希去重、远程写入标记。最近消息 ID 保留 100 条即可，应用重启后无需保留。

### 内容规则

- 只同步纯文字。
- 空字符串不发送。
- 中文、英文、Emoji、多行文字原样处理。
- 单条上限 1 MiB。
- 不尝试识别密码。
- 不将正文写入配置或日志。

## 11. 连接与重连

### 建立连接

1. 校验输入是否为 IPv4。
2. 禁止连接自己的 ZeroTier IP。
3. 使用 5 秒连接超时。
4. TCP 建立后发送 `hello`。
5. 未配对则进入配对，已配对则认证。
6. 成功后进入 `Connected`。

### 心跳

- 每 10 秒发送一次 `ping`。
- 连续 3 次没有 `pong` 则判定失联。
- 心跳不改变“最近同步”时间。

### 重连间隔

```text
2 秒 → 5 秒 → 10 秒 → 20 秒 → 30 秒
```

之后每 30 秒尝试一次，连接成功后重置。用户主动断开、解除配对、拒绝配对或认证失败时不自动重连。

双方同时主动连接时，通过比较 `device_id` 决定保留哪条连接，任何时刻只保留一个同步通道。

## 13. 错误和日志

| 场景 | 用户提示 |
|---|---|
| 未找到网卡 | 未发现 ZeroTier IP，请检查 ZeroTier 是否已经连接。 |
| TCP 超时 | 无法连接，请确认对方程序已经启动。 |
| 连接被拒绝 | 对方没有运行 ClipLink，或被防火墙阻止。 |
| 配对拒绝 | 对方拒绝了配对请求。 |
| 认证失败 | 配对信息已失效，请重新配对。 |
| 版本不兼容 | 双方版本不兼容，请更新 ClipLink。 |
| 内容过大 | 剪贴板文字超过 1 MiB，本次未同步。 |

日志可以记录时间、状态、IP、端口、消息类型、字节数和错误类型；禁止记录正文、共享密钥和完整认证材料。

## 14. Windows 防火墙

- 不关闭系统防火墙。
- 只为 ClipLink 和指定 TCP 端口创建最小规则。
- 优先绑定 ZeroTier IP，不监听 `0.0.0.0`。
- ZeroTier IP 改变后重新绑定。
- 安装时创建规则，卸载时删除规则。
- 自动处理失败时显示清晰说明。

### 阶段 7：后续认证

1. 实现随机挑战。
2. 使用共享密钥计算 HMAC。
3. 验证响应。
4. 为业务消息增加 HMAC。
5. 实现解除配对。

完成标准：已配对设备自动认证；错误密钥必然失败；未认证连接不能发送内容。

### 阶段 8：单机剪贴板监听

1. 创建剪贴板工作线程。
2. 每 300 毫秒读取纯文字。
3. 计算哈希并识别变化。
4. 读取失败时重试。
5. 暂停时不产生发送事件。
6. 超过大小限制时提示。

完成标准：记事本、浏览器、编辑器中的复制都能检测；图片和文件被忽略；相同文字不重复触发。

### 阶段 9：双向同步

1. 本地变化时发送剪贴板消息。
2. 接收端验证后写入剪贴板。
3. 增加消息 ID 去重。
4. 增加哈希去重和远程写入标记。
5. 更新最近同步状态。
6. 测试双方快速交替复制。

完成标准：A 到 B、B 到 A 均正常；每次复制只同步一次；不会无限回传；中文、Emoji 和多行文字不变。

### 阶段 10：自动重连和冲突处理

1. 实现退避重连。
2. 对方重启后自动恢复。
3. 网络断开后自动恢复。
4. 处理双方同时连接。
5. 用户主动断开时停止重连。

完成标准：连接状态准确；网络恢复后自动连接；始终只有一个通道；旧内容不补发。

### 阶段 11：托盘和开机启动

1. 创建系统托盘和菜单。
2. 拦截关闭窗口并隐藏。
3. 双击托盘打开窗口。
4. 接入开机启动插件。
5. 开机启动时默认静默到托盘。

完成标准：窗口关闭后同步继续；托盘可暂停、恢复、打开和退出；开机启动设置持久化。

### 阶段 12：安装包和防火墙

1. 配置名称、图标、版本和发布者。
2. 生成 Windows 安装包。
3. 创建最小防火墙入站规则。
4. 卸载时删除规则。
5. 测试普通用户安装、覆盖安装和卸载。

完成标准：全新电脑安装后可连接；卸载后不残留程序防火墙规则。

### 阶段 13：测试和发布

单元测试：IP 校验、消息编解码、HMAC、哈希、去重、重连退避和重复连接选择。

集成测试：配对允许/拒绝、自动认证、错误密钥、双向同步、大文本拒绝、断线重连和同时连接。

手工测试：中文、英文、Emoji、多行、快速复制、休眠唤醒、锁屏解锁、ZeroTier 断开恢复、开机启动、防火墙、升级和卸载。

发布标准：连续运行 24 小时无崩溃；同步 1,000 次无循环；网络恢复测试 20 次；日志无正文和密钥；安装、升级、卸载全部通过。

## 17. 里程碑

- M1 界面原型：展示 IP、状态和配对弹窗。
- M2 网络打通：两台电脑通过 ZeroTier 连接并交换设备名。
- M3 安全配对：首次确认和后续认证可用。
- M4 核心可用：双向文字同步稳定且不循环。
- M5 桌面体验：重连、托盘、暂停和开机启动可用。
- M6 可安装发布：安装包、防火墙和测试完成。

## 20. 最终定义

ClipLink 第一版只做一件事：两台已加入同一 ZeroTier 网络的 Windows 电脑，通过输入对方 IP、完成一次确认后，简单、稳定、安全地双向同步纯文字剪贴板。

任何不能直接增强这条主流程的功能，都不进入第一版。
